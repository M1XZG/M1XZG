## About

I'm based in the UK and currently work at [GitHub](https://github.com). Away from work, I'm usually writing Bash or Zsh scripts, adjusting some part of my home automation, or finding another job for a Raspberry Pi.

Several Pis keep things running around the house. A Raspberry Pi 4 with 8 GB of memory hosts custom Docker containers and Plex, while other projects include my own [kiosk configuration](https://github.com/M1XZG/Raspberry-pi-kiosk-config) and [ADS-B reception, decoding and sharing with Docker](https://sdr-enthusiasts.gitbook.io/ads-b/).

Coffee is a constant companion. Pumpkin Spice Latte season is still much too short.
